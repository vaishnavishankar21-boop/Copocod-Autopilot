# Copocod-Autopilot
Copado AutoPilot is a headless Salesforce DevOps orchestration platform built for the CopadoCON 2026 Hackathon. It combines a unified CLI (copado-hx), Model Context Protocol (MCP) integration, AI-agent workflows, and state-aware automation to enable autonomous Copado CI/CD, testing, and release management without requiring the Copado web interface.
